- Creation is easy to understand
- Structure -> these are kind of static thing by combining class and object , which are used to solve problem via behaviuor pattern.
  - This connection — how body, head, eyes, arms are attached — is structure.
  - Structure = who is connected to whom, how everything is organized. ( these are organised properly so that can use to solve some problem or act ) 
- Behaviour -> its like the pattern in code , to solve the problem. like concurrency pattern in golang etc.
  - These actions — walking, lighting, talking — are behavior.
  - Behavior = how something acts or responds. ( with eye we see and with ear listen, and do something like speak. )
